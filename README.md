# 📊 Machine Learning: Regression & KNN Classification

This project demonstrates the implementation of **regression** and **K-Nearest Neighbors (KNN) classification** using Python on a real dataset.

---

## Project Overview

The goal of this project is to explore fundamental machine learning techniques by applying:

* Regression for prediction tasks
* KNN for classification tasks

---

## Project Structure

```
.
├── regression.ipynb          # Regression models implementation
├── Knn_classification.ipynb  # KNN classification
├── telescope_data.csv        # Dataset used
├── Analog.py                 # Supporting script / preprocessing
```
